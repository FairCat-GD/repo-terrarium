# Bitmap font sources

Downloaded 2026-09-27 from Markus Kuhn, University of Cambridge:
https://www.cl.cam.ac.uk/~mgk25/download/ucs-fonts.tar.gz
Maintainer information and copyright statement:
https://www.cl.cam.ac.uk/~mgk25/ucs-fonts.html

4x6.bdf credits Janne V. Kujala. Both BDF headers state:
“Public domain font. Share and enjoy.”
Original BDF, README and AUTHORS are retained. Exported cells are exact subsets,
with no geometric modification or resampling. Indexed ink uses Botanical Cabinet slot 7.

Coverage: body = U+0020–U+007E (95). Headings = the same range excluding
U+0061–U+007A and U+0060, U+007B, U+007D, U+007E (65).
Total = 160 bitmap cells, including one space in each font. There are 95 unique
characters across the two repertoires. The inventory’s ~95 + ~40 is an approximate
135; heading punctuation is expanded to make its separate ~160 summary exact.
Heading lowercase input may map to uppercase; those aliases are not extra glyphs.
Fallback is U+003F. Non-ASCII repository names require a separate text policy;
this delivery makes no Unicode or localization coverage claim.
